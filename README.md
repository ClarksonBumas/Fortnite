# Fortnite Battle Royale Game 🎮

A browser-based Fortnite-style Battle Royale game built with vanilla JavaScript and HTML5 Canvas.

## Features

✨ **Gameplay Mechanics:**
- **Player Character** - Control with WASD keys, jump with SPACE
- **Shooting System** - Aim with mouse, click to shoot (limited ammo)
- **Enemy AI** - 10 AI opponents that chase and shoot at you
- **Health & Damage** - Take damage from enemy fire, collect health pickups
- **Loot System** - Enemies drop ammo and health packs when defeated
- **Victory Condition** - Eliminate all enemies to achieve Victory Royale!

## Controls

| Key | Action |
|-----|--------|
| **W/A/S/D** | Move left/right |
| **SPACE** | Jump |
| **MOUSE** | Aim gun |
| **CLICK** | Shoot |
| **E** | Reload (refill ammo) |
| **ESC** | Pause/Resume |

## How to Play

1. Open `index.html` in your web browser
2. Use WASD to move your character (green)
3. Move your mouse to aim
4. Click to shoot enemies (red)
5. Collect loot drops for health and ammo
6. Eliminate all enemies to win!

## Game Stats

- **Player Health:** 100 HP
- **Starting Ammo:** 30 rounds
- **Enemy Damage:** 10 HP per hit
- **Enemies:** 10 AI opponents
- **Game Duration:** 5 minutes

## Technical Stack

- **HTML5** - Page structure
- **CSS3** - Styling and UI
- **Vanilla JavaScript** - Game logic and canvas rendering
- **Canvas 2D API** - Graphics rendering
